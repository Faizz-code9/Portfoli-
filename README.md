## 📖 Project Overview & Description

**Mohammed Faizan's Portfolio** is a cutting-edge, developer-centric web application engineered to showcase advanced capabilities in **Artificial Intelligence, Agentic Systems, Embedded Hardware Security, and Full-Stack Engineering**.

Built with a **Cosmic Black Deep Space design language**, this portfolio rejects generic template layouts in favor of an interactive, physics-driven experience that merges high-performance graphics with silky micro-interactions:

- **Immersive 3D & 2D Physics:** Combines custom Three.js mathematical wireframes with a full Matter.js rigid-body physics arena.
- **Fluid & Seamless Animations:** Powered by Framer Motion, dynamic SVG vector paths, and GPU-accelerated CSS transforms.
- **Recruiter & Engineer Friendly:** Features an in-app PDF document previewer for instant resume inspection without download barriers, stepped academic/award timelines, and live GitHub/LeetCode telemetry.

---

## 🌟 Key Features

### 🌌 1. Cosmic Black & Constellation Particle Engine
- **True Deep Space Background (`#020408`)**: Rich obsidian dark canvas with high-blur (75px) subtle cosmic nebula accents.
- **Dynamic 2D Constellation Mesh**: Floating starlight particles connecting with proximity-based translucent vector lines and real-time cursor attraction.

### ⚡ 2. Interactive 3D Wireframe Canvas
- Built with **Three.js** rendering a dynamic wireframe geometry with mouse parallax tracking, ambient lighting, and rotational inertia.

### 🎮 3. Interactive 2D Physics Skills Playground
- Powered by **Matter.js**:
  - Drag, throw, and fling skill blocks with realistic mass, restitution, and friction.
  - **Invert Gravity (Zero-G / Upward / Downward)** and **Reset Physics** controls.
  - Full touch-screen support (`touch-none`) on iOS and Android.

### 💫 4. 360° Revolving Technology Orbit
- Continuous 360° orbital revolution of technology badges around the central profile avatar.
- Integrated **counter-rotation physics** ensuring badges always stay upright while in transit.
- Dual-tab container featuring **Stepped Education Timeline** and **2-Column Achievements Grid** with certificate watermark backgrounds.

### 🖼️ 5. 3D Tilt Project Mockup Showcase
- 2-column interactive showcase with **perspective 3D mouse tilt**, modal expansion, key features bullet checks, and quick links to live code & demos.

### 📜 6. Realistic Certificate Envelope Slider
- Custom arch-cut envelope pockets with rich gradients (Amber, Cyan, Blue, Rose, Purple, Emerald).
- Vintage parchment certificate sheets with wax-seal stamps that **slide smoothly upwards** on hover/tap.
- Unclipped 3D pop-up animation and direct `View` trigger.

### 📄 7. In-App Resume Document Previewer
- In-website embedded PDF document viewer matching the mobile app card design.
- Toggle between **Technical 1-Page Resume** and **Complete Academic CV (With Photo)**.
- Floating action buttons: `View Fullscreen`, `Share Link`, and `✕ Close`.

### 📱 8. 100% Mobile & Touch Optimized
- Fluid responsive layouts, scaled orbit tracks, mobile slide-down navigation drawer, and touch gestures.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **pnpm** / **yarn**

### 2. Clone the Repository
```bash
git clone https://github.com/Faizz-code9/Portfolio.git
cd Portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Local Development Server
```bash
npm run dev
```
Open your browser and navigate to:
```
http://localhost:5173/
```

### 5. Create Production Bundle
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
